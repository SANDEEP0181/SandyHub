Privacy

SandyHub is designed to process supported tools in your browser where practical. Some features, such as Image to URL, require sending the selected file to a third-party hosting service to create a shareable URL.

Image uploads

The Image to URL tool uploads the image you select to Cloudinary using an unsigned upload preset. The resulting public image URL is returned to your browser. Do not upload private, confidential or sensitive images.

Local processing

Tools that are designed for browser-only processing do not need to upload your input to SandyHub servers. Your browser may still contact third-party services when a tool explicitly says it uses one.

Changes

This privacy page may be updated as SandyHub adds features, analytics or advertising. The latest version will be published here.
